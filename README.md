# Quiz Platform

A full-stack quiz application built with **React** (frontend), **Node.js + Express** (backend), and **MongoDB**. Users can enter their name, take timed quizzes, submit answers, and view a leaderboard of top scores.  

>** Developed as part of my internship project in compliance automation and AI-based reporting systems.**


---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

## Features

- User-friendly quiz interface with timer and progress bar
- Dynamic questions loaded from MongoDB
- Multiple-choice questions with score calculation
- View top scores on a leaderboard
- Fully responsive design with glassmorphism-style cards
- Easy to deploy on cloud platforms

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

## Tech Stack

**Frontend:**  
- React.js  
- Axios for API calls  
- CSS for styling (custom and glassmorphism)

**Backend:**  
- Node.js + Express.js  
- MongoDB for storing questions and submissions
- Mongoose ODM
